# 144p Group

Reszponzív, magyar nyelvű agency oldal. Node.js 20+ szükséges, külső npm-függőség nélkül.

```sh
npm start
```

Alapértelmezett port: 3000. Felülírható a `PORT` változóval. Az oldal a `public/` könyvtárban szerkeszthető.

## Publikálás előtti tartalmi feladatok

- A jrepas.hu és az Upwork oldal az elkészítés környezetéből nem volt elérhető (proxy HTTP 403). A megjelenés önálló tervezet, nem ellenőrzött másolat.
- A szolgáltatások egyelőre mintatartalmak: egyeztetni kell az Upwork profil tényleges kínálatával.
- A csapat neveit, személyes bemutatkozásait és valódi fotóit véglegesíteni kell. A jelenlegi SVG-k jelölt portréhelyek, nem valódi személyfotók.
- Minden kapcsolatfelvételi gomb a megadott hivatalos Upwork agency profilra mutat.

Az oldal Google Fonts betűtípusokat kér le, elérhetetlenség esetén rendszerbetűkre vált. A grafikák helyiek; nem igényelnek külső képszolgáltatást.
